How to Load as a Chrome Extension

1

Download / Clone Repo

Download the repository as a ZIP from GitHub or keep your local socialmedia folder.

2

Open Extensions

In Chrome or Brave, navigate to chrome://extensions in your address bar.

3

Developer Mode

Toggle the Developer mode switch in the top-right corner to ON.

4

Load Unpacked

Click Load unpacked and select this folder. StudySocial will appear in your toolbar!
